# Panda Swap

I am providing a NEW Panda 3D file that already has the correct rig, skeleton, skin weights, and setup.

IMPORTANT:

- Remove the OLD Panda character that is already inside the app completely.

- Add and use ONLY the NEW Panda 3D file that I am providing.

- Do NOT create another Panda.

- Do NOT modify, re-rig, retarget, deform, rotate, resize, or alter the new Panda’s rig, skeleton, skin weights, proportions, model, textures, or animations.

- Keep the new Panda exactly as provided in my file.

- Position the new Panda naturally in the same character position where the old Panda was.

DO NOT CHANGE ANYTHING ELSE IN THE APP:

- Do NOT change the background.

- Do NOT change the lighting.

- Do NOT change the camera/layout.

- Do NOT change the UI.

- Do NOT change buttons.

- Do NOT change sounds/music.

- Do NOT change the existing animations or functionality.

- Do NOT change colors, effects, or other elements.

ONLY replace the existing old Panda with the NEW Panda file I provide. Everything else must remain exactly the same.
